Marks and Grade Calculator📊

A simple and interactive web application built with Python and Streamlit to calculate student's total marks, percentage, and grade.

Features:

-> Enter student name
-> Enter number of subjects
-> Enter marks for each subject
-> Automatically calculate total marks
-> Calculate percentage
-> Automatically assign grade
-> Display Pass/Fail result
-> Validate marks between 0 and 100
-> Simple and user-friendly interface

Technologies Used:

-> Python
-> Streamlit

Installation:

Clone the repository:

git clone:
the link should be pasted here

Move into the project folder:
cd marks_and_grade_calculator

Install the required package:
pip install -r requirements.txt

Run the Application:
streamlit run app.py

The application will open in your web browser.
